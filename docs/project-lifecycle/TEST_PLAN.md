# 🧪 برنامه جامع اجرا، آزمون و تضمین کیفیت (Test & QA Plan)
# Maya Spirulina Platform | سند استراتژی و سناریوهای آزمون

---

## ۱. استراتژی تضمین کیفیت (QA Strategy)
تضمین کیفیت در مایا اسپیرولینا بر اصل **«انتشار بدون پایش و آزمون ممنوع است»** استوار است:
1. **آزمون‌های زمان کامپایل (Static & Compile Checks):** بررسی تایپ‌های تایپ‌اسکریپت و بیلد استاندارد Next.js (`npm run build`).
2. **آزمون‌های مسیر اصلی (Happy Path E2E):** تست جریان کامل یک مشتری واقعی از اولین کلیک تا دریافت فاکتور.
3. **آزمون‌های حالت‌های خرابی (Failure & Edge Cases):** سناریوهای قطعی شبکه، خطا در پرداخت، اتمام موجودی و ورودی‌های نامعتبر.
4. **آزمون‌های امنیتی (Security Hardening):** تست ریت‌لیمیتینگ، جعل درخواست و دسترسی‌های غیرمجاز.

## ۴. چک‌لیست بازرسی امنیتی و پایداری (Security & Reliability)

- [x] **اعتبارسنجی ورودی‌ها (Sanitization):** تمام ورودی‌های فرم‌ها در کلاینت و سرور پاکسازی می‌شوند.
- [x] **تنظیمات کوکی سشن:** کوکی `auth_token` دارای ویژگی‌های `HttpOnly`، `SameSite=Lax` و `Path=/` است.
- [x] **کنترل ریت‌لیمیتینگ روی روت‌های حساس:** روت‌های `/api/auth/otp/*` با ردیس یا بافر داخلی محافظت می‌شوند.
- [x] **عدم افشای اطلاعات فنی (Stack Trace Leaks):** در محیط پروداکشن، پیام‌های خطای سرور بدون افشای جزئیات دیتابیس به کلاینت ارسال می‌شوند.
- [x] **کامپایل بدون خطا:** اجرای دستور `npm run build` با خروجی `Exit Code: 0` برای تمام ۳۰ روت.

## ۵. فرآیند تست قبل از هر انتشار (Pre-Release Gate)
پیش از تحویل به محیط نهایی یا انتشار نسخه جدید:
1. اجرای بیلد کامل: `npm run build`.
2. بررسی لاگ‌های تایپ‌اسکریپت و حل هرگونه هشدار.
3. تست جریان خرید با مرورگر دسکتاپ و شبیه‌ساز موبایل (عرض ۳۷۵ پیکسل).
4. تایید ثبت سفارش تستی و بررسی صحت ارقام و فرمت تومان در فاکتور.

## آزمون خودکار e2e (Playwright)

`e2e/purchase.spec.ts` مسیر اصلی درآمد را از ابتدا تا انتها آزمایش می‌کند: ورود مشتری، انتخاب بسته، پرداخت در درگاه آزمایشی، نمایش سفارش در «سفارش‌های من»، ثبت ارسال توسط انباردار و دیدن کد رهگیری توسط مشتری. همچنین بررسی می‌کند که مبلغ ارسالی از مرورگر نادیده گرفته شود و مشتری به بخش‌ها و APIهای کارکنان دسترسی نداشته باشد.

```bash
npx prisma migrate deploy && npm run db:seed
npm run test:e2e        # سرور توسعه را با PAYMENT_GATEWAY_MODE=mock خودش بالا می‌آورد
```
